Help & video integration

Build your infographic, preview it, then export it as an overlay.

Add elements from the left column, select them in the viewer to move them (drag), resize them (handles) and rotate them (round handle above the selection). Drag a rectangle on empty space to select several elements at once, Ctrl+click to add or remove one from the selection, then move, nudge (arrows), duplicate (Ctrl+D) or delete the whole group together — alignment buttons work within the selection when several elements are selected. The timeline at the bottom shows the timing of every element: drag a block to move it, pull its right edge to change its duration, click the small + at the end of a track to add an animation (in or out) at the playhead, or right-click anywhere on a track to add an exit (or entry) animation exactly where you click. Space = play/pause, Del = delete, Ctrl+D = duplicate, arrows = nudge by the pixel.

Use the Reference video button at the top right of the viewer, or drag & drop a video file onto the scene: the video sits behind your elements as a visual and audio guide, and the project duration automatically locks to the video duration (the duration selector is disabled then; remove the video to get manual duration back). Then add as many animations as you need across the whole duration: an in animation makes the element appear, an out animation makes it disappear, and the time in between stays unchanged. The video is synced to the timeline (play, pause, scrub), with adjustable volume and opacity. It is never included in exports (HTML, PNG, WebM stay 100% transparent) and is never saved with the project. You can also drop media files (videos, images, audio) directly on the timeline (V1 / A1 lanes) to build a montage: move the clips, trim their edges, split them at the playhead (S) — clips live in the session and are included in the final video export.

Open Auto subtitles in the left column: the audio of the reference video, of the timeline montage (A1 audio + the sound of the video clips, mixed at their exact timeline positions — volumes and trims respected), or of any audio file is transcribed by OpenAI's Whisper, running entirely in the page via Transformers.js (ONNX, loaded from the CDN). Multilingual models — French and English included (+ 96 other languages); pick the language or let Whisper detect it. The model (~40 / ~78 MB) downloads on first use, then is cached by the browser — later uses are offline. Generation runs in a background thread (the page never freezes — and if this browser or page refuses background threads, generation continues automatically on the main thread with the same progress info) with a live progress bar: phase milestones (Audio → Engine → Model → Transcribe → Build), download percentage with speed and time estimates, transcription part by part with the words detected so far, elapsed time — and a Stop button that cancels anytime (the downloaded model stays cached). Word timings are aligned to the speech actually detected in the audio: a line appears exactly when its first word is spoken, never creeping through silences. Choose a render style — Classic, Karaoke (word-by-word highlight), TikTok (bold + outline), Box / CC, Minimal or Word pop (one word at a time) — then generate. The resulting “Subtitles” layer behaves like any element: move it, resize it, restyle it, re-group its lines (max words / max duration), add in/out animations — and fix the text line by line in its panel (“Transcript — fix the text”), with the original one click away. It is included in every export (standalone HTML, PNG, WebM) with the same look, and its transcript is saved with the project.

With nothing selected, the right column shows a Scene section: pick a background color (or stay transparent — the checkerboard means alpha). The color is painted in every export: standalone HTML, PNG sequence (frames become opaque), WebM, final video and thumbnails. Perfect for intros, outros and standalone posts; clear it to go back to overlay-ready transparency. The reference video, when present, still sits on top of that background in the viewer and in the final export.

The Templates modal is a library of external .json template files — nothing is baked into the page. Import files with “Import…”, drag & drop them anywhere on the open modal, or keep them in a templates/ folder next to the HTML file (auto-detected when served over http, or use Folder… / Reload). Build a scene you like and hit “Save current scene as template…”: a .json file is downloaded and the template lands in the library. Applying a template rescales it to the current format; with “Clear the current scene first” it also restores its duration and background — every element stays editable and the action can be undone (Ctrl+Z).

Exports (PNG, WebM, standalone HTML) cover the whole project duration: only your animations are encoded, periods without animation stay unchanged — transparent, or painted with the scene background color when one is set — so the layer overlays your video with perfect frame-by-frame timing.

Put the HTML file in a folder and create a fonts/ folder (.ttf, .otf, .woff, .woff2 files) and a stickers/ folder (png, jpg, webp, gif, svg images) next to it. Serve the folder from a small local server — python3 -m http.server then open http://localhost:8000/overgraph-studio.html — and everything you drop in those folders shows up automatically in the studio (Reload button to refresh without restarting). Without a server (opening the file directly), use the Folder… (Chrome/Edge) or Import… buttons — manual imports are kept between sessions. Fonts apply to texts and counters (including PNG/WebM exports) and are embedded in the standalone HTML export; stickers are added with one click on their thumbnail and can be placed, resized and animated like any other element.

Export ▸ Project (.zip) packs a project.json (every element, the format, the duration and all animations) together with the custom fonts and stickers actually used by the project. The reference video is never included — it is a preview-only guide by design. Use Open in the top bar to re-open a project .zip (or a bare .json): fonts and stickers are re-registered automatically and the scene, timeline and animations are restored exactly as they were.

Undo / redo: Ctrl+Z and Ctrl+Shift+Z (or Ctrl+Y), 120 steps. Guides (button at the bottom right of the viewer): magnetic snapping to the scene edges, centers and other elements (Alt bypasses it, Shift locks the axis), plus safe zones for TikTok / Reels / Shorts UI, rule of thirds, center cross and grid. Align buttons in the Position & size panel, and Templates at the top of the left column.

ffmpeg -i video.mp4 -framerate 30 -i frame_%05d.png \
  -filter_complex "[0:v][1:v]overlay=0:0" -c:a copy output.mp4
ffmpeg -i video.mp4 -i overlay.webm \
  -filter_complex "[0:v][1:v]overlay=0:0" -c:a copy output.mp4
By default the infographic background is transparent (checkerboard in the editor); a scene background color, if you set one in the Scene section, is painted in every export instead. The exported WebM carries a real alpha channel (dual video stream via WebCodecs, VP9 when available) rendered transparent in Chrome and compatible players. For ffmpeg compositing, the PNG sequence remains the most reliable route. Tip: set the format to exactly match the host video (e.g. 1080×1920) for a perfectly aligned layer.
